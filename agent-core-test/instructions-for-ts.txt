Standalone TypeScript Agent Instructions
========================================

This runs a TypeScript equivalent of agent.py directly from agent-core-test.
It does not use the AgentCore CLI or deploy an AgentCore Runtime.

Files added
-----------
agent.ts       Standalone Strands agent with calculator and weather tools.
package.json   npm scripts and the Strands, Zod, TypeScript, and tsx packages.
tsconfig.json  TypeScript compiler settings used by the build check.
package-lock.json  Generated by npm install to lock dependency versions.

The TypeScript agent uses the same Bedrock model as agent.py:
- Model profile: eu.amazon.nova-lite-v1:0
- Region: eu-north-1
- Weather tool: fixed demo response, "Very cold"; it is not live weather.
- Calculator tool: supports two numbers with +, -, *, or /.

Prerequisites
-------------
- Node.js 22 or newer and npm. Check with:

    node --version
    npm --version

- AWS CLI credentials configured for your account. Check which identity is
  active with:

    aws sts get-caller-identity

- Permission to invoke the Nova Lite inference profile in eu-north-1.

The AWS JavaScript SDK uses the standard AWS credential provider chain, which
can read environment credentials, shared AWS config/credentials files, and
AWS_PROFILE. The model's region is set in agent.ts. Never put AWS keys in the
source files or commit them to source control.

Install dependencies
--------------------
Open PowerShell in the agent-core-test folder:

    Set-Location C:\Dev\udemy-agent-core\agent-core-test
    npm install

This installs packages from package.json and creates or updates
package-lock.json. It does not alter the Python .venv or requirements.txt.

Check the TypeScript build
-------------------------
    npm run build

This runs tsc --noEmit. It checks types without generating JavaScript files.

Run the agent
-------------
    npm run agent -- --prompt "Calculate 24 times 7 and tell me the weather."

The npm script uses tsx to execute agent.ts directly. The `--` passes the
following `--prompt` argument to the agent script. A successful response should
include 168 and the demo weather result, "Very cold".

This sends a Bedrock model request and may incur charges. It runs locally and
does not create AWS infrastructure. CDK, ECR, AgentCore CLI, and an AgentCore
Runtime are not needed for this standalone run.

What changed from agent.py
--------------------------
- The Strands imports are from the TypeScript package @strands-agents/sdk.
- The Bedrock model is configured with `modelId` and `region` in TypeScript.
- Zod schemas define the calculator and weather tool inputs.
- The calculator is implemented as a TypeScript tool accepting two operands
  and an operator; the Python calculator tool accepts expressions.
- argparse is replaced with a small `--prompt` parser using process.argv.
- agent.invoke(prompt) is asynchronous, so the script awaits its response.

Troubleshooting
---------------
"npm is not recognized": install Node.js 22 or newer, then open a new
PowerShell terminal.

"AccessDenied" or model not found: confirm `aws sts get-caller-identity`,
that the active AWS identity may invoke Bedrock, and that the Nova Lite profile
is available in eu-north-1.

To use a named AWS CLI profile for this PowerShell session:

    $env:AWS_PROFILE = "your-profile-name"

A build success verifies TypeScript types, not AWS connectivity. Run the agent
command above to test the Bedrock call.
